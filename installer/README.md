# 💻 설치 (Installer / Setup) 관리소

릴리 단말기 신규 설치 및 재설치를 위한 **윈도우 전용 NSIS 단독 인스톨러**입니다.

---

## 📋 설치 관리 규격
1. **고정 파일명**: **`haste_client3-setup.exe`** (단일 고정 명칭 영구 사용)
2. **설치 경로**: `%LOCALAPPDATA%\haste_client3\` (고정 GUID 기반 100% 덮어쓰기 업데이트)
3. **데이터 보존**: 기존 SQLite DB(`%APPDATA%\haste_client3\haste_client.db`) 설정 및 레시피 100% 안전 보존
4. **보안 인증**: 파트너 설치 비밀번호(`dkfptm7777`) 및 마스터 비밀번호(`admin8113`) 이중 검증
