# 🔒 정식버전 (Official Production Version) 관리소

김포운양역점 및 연구소 실기기 물리 제어 100% 검증을 통과한 **전국 가맹점 대상 정식 상용 배포 버전**입니다.

---

## 📋 정식버전 관리 원칙
1. **버전 명명 규칙**: `v<Major>.<Minor>.<Patch>` (예: `v3.3.1`, 접미사 `r` 없음)
2. **영구 보존 락 (Permanent Lock)**: 정식 상용 버전은 롤링 삭제 대상에서 100% 제외되며 영구 보존됩니다.
3. **전국 가맹점 원격 배포**: 본사 관리자 승인 시 전국 모든 릴리 단말기에 안전하게 일괄 자동 업데이트됩니다.
