# ⚡ 핫패치 (Hotpatch) 배포 관리소

HASTE 플랫폼의 기능 개선, UI 최적화 및 현장 실기기 검증을 위한 **개발/테스트 채널 전용 핫패치 번들**입니다.

---

## 📋 핫패치 관리 원칙
1. **버전 명명 규칙**: `v<Major>.<Minor>.<Patch>r<Revision>` (예: `v3.3.1r154`)
2. **최신 10개 롤링 보존**: 시스템 리소스 및 CDN 최적화를 위해 **상시 최신 10개 버전만 자동 유지**되며, 이전 버전은 롤링 자동 정리됩니다.
3. **경량화 배포**: 미디어 에셋을 제외한 순수 코드 번들(~50MB)로 초고속 핫패치를 지원합니다.
